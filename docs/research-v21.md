목표: 3초 안에 읽히는 홈, 한 가지 절제된 팔레트, 크고 자신감 있는 숫자, 적지만 풍부한 카드, 살아 있는 모션.

## 결정한 시스템

- 팔레트: 배경 #05070B, 표면 rgba(255,255,255,.035), 선 rgba(255,255,255,.07), 글자 #F2F4F8 / #98A0AE, 강조색은 아이스 블루(#8AB4FF) 하나. 증감은 초록(#4ADE80)/로즈(#FB7185)만.
- 타이포: Pretendard, 숫자는 Space Grotesk(tabular). 히어로 숫자 52–64px, 600, 자간 -0.04em.
- 간격: 8pt 그리드, 카드 패딩 20–24px, 카드 사이 14px, 모서리 22px.
- 첫 화면에는 타일 벽 없음: 오브+인사+AI 한 줄 → 순자산+스파크라인 → 오늘의 3가지 → 대표 AI 제안 → (스크롤) 재미 캐러셀 → 지도 → 허브 문.
- 모든 기능은 '전체 기능' 런처와 각 허브 아래쪽 리스트로 그대로 접근.
- 모션: 스프링(cubic-bezier(.2,.9,.25,1.12)) 허브 전환, 숫자 카운트업, 차트 선 그리기, 스켈레톤 시머, 버튼 눌림 0.97 스케일, 스크롤 패럴랙스. `prefers-reduced-motion`이면 전부 끔.
- 지도: 다크 Esri 타일 기본, 실패 시 OSM → Esri Street 자동 전환(CARTO는 API 키 워터마크라 제외). 미니맵은 스크롤을 가로채지 않는 미리보기(탭하면 전체 지도), 전체 지도는 화면 높이를 꽉 채움.

## AI 원칙

- 개인 데이터는 브라우저에서 제3자 AI로 보내지 않음. 생성은 신뢰된 박스(루틴 에이전트 + scripts/ai-insights.py)에서만, 결과는 암호화 payload로만 배포.
- 모든 제안은 근거 필드(src)를 표시, 추정치는 '추정' 배지, 금융은 '조언 아님', 부업은 L-1 비자 주의.
