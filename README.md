# 혁진님의 JARVIS (v8 · 탭 + 검색 + 커맨드 센터)

봇 8개, 돈, 투자, 일정, 메일, 파일을 한곳에서 보는 한국어 개인 대시보드입니다(PWA, 블랙/시안 테마).

- **공개 URL (GitHub Pages):** https://lhj810-USA.github.io/bot-dashboard/ — 잠금 화면이 먼저 나오고, 접근 코드가 있어야 볼 수 있습니다.
- **로컬 서버 (박스 내부 전용):** http://localhost:8787 (`server.py`). 명령 대기열과 Web Push API를 제공합니다.

## 화면 구성
- **하단 탭:** 홈 / 돈 / 투자 / 일정·메일 / 봇 / 더보기. 탭 배지는 새 항목 수입니다.
- **검색 '무엇이든 검색':** 거래, 메일, 주변 행사, 일정, 봇, Drive 파일, 정기결제를 한 번에 찾습니다. 거래를 검색하면 합계도 보여 줍니다.
- **홈:**
  - 오늘의 브리핑(줄을 탭하면 상세로 이동)
  - 📌 관심 고정 줄: 순현금, 부업, 자동 매매, 결정, 가족·행사, 영어
  - 커맨드 센터 타일: 휴대폰 2열, 데스크톱 4열. 타일마다 지표, 스파크라인 또는 게이지, 상태 색, 한 줄 설명, NEW 개수, 데이터 신선도(⟳ n분 전)가 나옵니다.
- **1탭 드릴다운:** 모든 숫자는 한 번 탭하면 상세로 들어갑니다. 예: 카테고리 → 거래 목록 → 거래 상세 → 같은 가맹점.
  - 상단 **← 뒤로** 버튼은 홈이 아닌 모든 화면에 항상 보입니다.
  - 주소 해시(`#money`, `#tx:<id>` 등)로 이동하므로 브라우저 뒤로 가기도 됩니다.
- **명령 바와 음성:** 🎤 버튼에서 "집사, …"처럼 말하면 해당 봇이 선택됩니다. ▶ 버튼은 브리핑을 읽어 줍니다. 명령은 Pages에서는 클립보드에 복사되고, 로컬에서는 대기열(봇에 자동 전달되지 않음)에 저장됩니다.
- **없는 데이터:** 지어내지 않습니다. `—`, `데이터 없음`, `연결 필요`, `추적 시작 필요`로 표시합니다.

## 개인정보 모델
- 저장소에는 **암호문 `payload.enc.json`만** 올라갑니다.
  - 암호화: AES-256-GCM. 키는 접근 코드에서 PBKDF2-SHA256 310,000회로 만듭니다.
  - 복호화는 브라우저 안(WebCrypto)에서만 합니다. CDN은 쓰지 않습니다.
- 접근 코드, 원본 수집 데이터(`collected.json`), NEW 추적, VAPID 키는 모두 저장소 밖 `/workspace/bot-dashboard-secrets/`(권한 600)에 있습니다.
- `data.json`과 `status/*.json`은 git에서 제외합니다. 단, 과거 커밋 기록에는 봇 설명과 요약 평문이 남아 있습니다.
- '이 기기 기억'을 켜면 접근 코드를 그 브라우저의 localStorage에 저장합니다. ⏻ 버튼을 누르면 지워집니다.

## 새로고침 방법
- **봇 상태는 자동입니다.**
  - 각 봇이 `status/<id>.json`을 쓰면 `scripts/publish-loop.sh`가 5분마다 다음을 실행하고, 바뀐 경우에만 push합니다.
  - 순서: `update-data.py` → `build-payload.py`(암호화)
- **금융, 메일, 일정, Drive, GitHub, X는 수동입니다.**
  - 이 커넥터는 에이전트 도구로만 읽을 수 있습니다(읽기 전용).
  - Grok Bot에게 **"JARVIS 업데이트"**라고 말하면 에이전트가 다시 수집해 `collected.json`을 갱신하고, 다음 루프에서 암호화해 게시합니다.
  - 각 타일의 ⟳ 표시가 마지막 수집 시각입니다.
- ⟳ 버튼은 게시된 최신 암호문을 다시 받아 해독합니다. 새로 수집하지는 않습니다.

## 파일
- `index.html`: 단일 파일 앱(잠금, 탭, 검색, 드릴다운, 명령, 음성, 푸시)
- `sw.js`: 캐시 `bot-dash-v8-tabs`, payload는 network-first
- `scripts/update-data.py`: 봇 프로필과 상태를 합쳐 data.json(로컬)을 만듭니다.
- `scripts/build-payload.py`: 브리핑, 피드, 금융·메일·일정 등을 묶어 암호화합니다(v3 페이로드).
- `scripts/publish-loop.sh`: 5분 루프
- `server.py`: 로컬 API
- `status/README.md`: 봇 상태 보고 형식

## v12 · jarvis10 — AI · 부자되기 · 완전 커스터마이즈
파일: `js/v12a.js` (커스터마이즈·팔레트·카테고리), `js/v12b.js` (부자되기), `js/v12c.js` (AI), `css/v12.css`, `scripts/ai-brief.py`. SW 캐시 `bot-dash-v12*`.
- **AI 브리핑** (`#ai`): 박스 `scripts/ai-brief.py`가 5분마다 실제 거래·시세로 이상 징후(카테고리 급증·평소보다 큰 결제·새 정기결제)·위험·기회·다음 3가지 행동을 **규칙·통계로** 계산 → 비밀 폴더 `ai.json` → 암호화 페이로드. LLM 호출·외부 전송 없음. 브라우저 '기기 내 인사이트'는 요일·주말·가맹점 집중도·주간 추세 등을 즉시 계산.
- **AI 어시스턴트** (`#ai:ask`): 질문(타이핑·음성) + 문맥 칩(돈·부자되기·투자·브리핑·뉴스·습관) → 프롬프트 생성 → 클립보드 복사 또는 명령 바 전송으로 Grok Bot에 전달. 카테고리별 프롬프트 라이브러리(비밀 설정). Chrome 내장 Prompt API(`window.LanguageModel`)가 있을 때만 '기기 내 AI' 버튼 노출. API 키를 웹에 두지 않음. 명령 바에서 `자비스 …` / `AI …` 입력 시 어시스턴트로 이동.
